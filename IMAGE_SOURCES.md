# FoodFusion sample image URLs

The database stores remote image URLs in `image_path` and `thumbnail_path`. These photographs were found through web image search and are hosted by Unsplash; no AI-generated images are used.

Members also add community images by pasting a direct HTTPS image URL into the My Wall form. FoodFusion does not generate or upload those images.
